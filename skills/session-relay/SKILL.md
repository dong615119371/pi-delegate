# 跨会话协同手册

跨会话通信用于**持久、有独立上下文的长线协作**（如专职审查员、架构监督）。不是跑腿外包，更不是无头子任务。底层基于 Node 原生命名管道与本地内存 Socket 通信，无公共文件黑板报。

## 0. 选用判定

| 场景 | 选型 | 为什么 |
| --- | --- | --- |
| 找人审代码、要对方思考并给出结论 | `ask_session` | 内存管道长连接阻塞等待，拿回最终结果，闭环接力 |
| 仅通知状态，不需要回复 | `send_session` | 异步即发即走（2ms 直达），进入对方排队队列 |
| 对方尚未存在，需要长驻伙伴 | `spawn_session` | 原生持久独立进程，脱离后台作业系统，自动建立 IPC 管道 |
| 确认谁存活、查明会话 ID | `list_sessions` | 探测活动管道与 API，查明再发，禁止盲猜 |
| 查对方历史记录与上下文 | `read_session` | 顺着内存管道调阅历史消息 |

**严禁**：用 `bash` 执行 `pi` 或 `sleep | pi` 伪造后台会话——那是任务，不是会话；会吃超时被杀，还会刷屏。长驻会话一律走 `spawn_session`。

## 1. 寻址纪律

发信必先寻址：

| 情况 | 传参 | 表现 |
| --- | --- | --- |
| 明确知道 `ses_xxx` 或 `uuid` | 传确切 ID | 精准命中管道，最快 |
| 只知道对方名字（如 "audit"） | 传唯一名称子串 | 仅匹配 1 个时自动解析；匹配多个时报错拒绝 |
| 拿不准名字或 ID | 先调 `list_sessions` | 查到确切 ID 再发 |

**禁止盲猜名称**：若同名会话 ≥2 个，工具将直接拒绝。若目标会话未开机或已退出，管道连接将立即拒绝，绝不静默入死信。

## 2. 提问与协作纪律 (`ask_session`)

`ask_session` 通过内存长连接阻塞当前回合直到对方完成思考并返回结论。

1. **任务自包含**：对方看不见你的当前对话。提示词内必须包含涉及的**绝对路径**、改动意图、重点审查维度。
2. **大报文规范**：通信报文安全上限为 24,000 字符。若需传递完整文件大 Diff 或巨量日志，**必须先写临时文件并传递绝对路径**。
3. **拿到结论立即行动**：工具返回即为对方最终结论。直接针对结论修复或推进，**严禁向用户汇报“我已问过对方”等中转废话**。
4. **防死循环上限**：同一议题在会话间往返**不得超过 3 轮**。超过 3 轮仍有分歧，停下问用户。
5. **禁止礼貌客套**：提示词直奔主题，严禁“你好”、“请问在吗”、“收到谢谢”。

## 3. 伙伴拉起纪律 (`spawn_session`)

1. **CWD 必须为真实存在的绝对路径**。
2. **按需设 TTL**：默认 8 小时。临时协作可设短（如 1800 秒）。
3. **拉起即就绪**：会话在后台静默运行并自动开启命名管道监听，随后直接调 `ask_session` 或 `send_session` 与其对话。
